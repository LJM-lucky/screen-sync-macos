# 屏幕随光 · ScreenSync

屏幕随光是一款 Apple Silicon Mac 的菜单栏应用。它读取 MacBook 内屏的实际亮度。当 macOS 自动调光或你按下亮度键时，应用通过 DDC/CI 调节外接显示器的背光。每台外屏可以使用独立的校准曲线，让不同显示器在偏暗和偏亮的环境下都更容易匹配。

[下载 macOS 安装包](https://github.com/LJM-lucky/screen-sync-macos/releases/latest)

## 系统要求

- Apple Silicon Mac，macOS 26 或更新版本。已在 M1 Pro 和 macOS 27.3 上验证。
- 自动跟随需要一块正在使用的 Mac 内屏。开启 macOS 的「自动调节亮度」后，应用会跟随系统根据环境光做出的调整。
- 外接显示器与连接链路须支持 DDC/CI 亮度读写。显示器的实体菜单如果有 DDC/CI 开关，请将它打开。部分扩展坞、转接器或显示器模式可能会阻止控制信号通过。

## 安装与启动

1. 在 Releases 页面下载 `ScreenSync-v1.1.0-macOS-arm64.zip`，解压后把「屏幕随光.app」拖到「应用程序」。
2. 打开应用，点击菜单栏里的太阳图标，选择「打开设置与校准」。
3. 第一次启动会尝试注册登录项。设置窗口底部的「登录时启动」可以随时关闭或重新开启。需要系统批准时，应用会提供前往系统设置的入口。

发行包使用临时签名，尚未经过 Apple 公证。如果系统拦截首次启动，请先确认下载来自本仓库并核对 Release 中的 SHA-256，再按 Apple 的说明在「系统设置 → 隐私与安全性」中为这个应用单独授权。[Apple 支持](https://support.apple.com/zh-cn/102445)

## 使用说明

| 功能 | 操作 |
| --- | --- |
| 自动同步 | 菜单栏的「同步外屏亮度」控制所有外屏。设置中可用「同步此屏」单独控制一台。 |
| 跟随延迟 | 在设置顶部拖动滑块或输入 0–5000 毫秒。0 表示检测到变化后立即发送指令。设为 1000 表示内屏亮度稳定 1 秒后再发送。实际响应还取决于检测和显示器通信耗时。 |
| 微调与范围 | 选择外屏，设置微调、最低和最高亮度。应用先根据校准曲线算出目标，再应用微调和上下限。菜单栏也能快速微调。 |
| 临时接管 | 选择 5、15、30 或 60 分钟。接管期间可以手动设置外屏亮度，到期恢复同步。 |
| 重新检测 | 唤醒或重新连接后若仍无响应，点击设置底部的「重新检测」。 |

### 校准单台外屏

1. 左侧选中要校准的显示器，点击「校准亮度」。
2. 如果需要统一的参照画面，点击「显示对照」。内屏和选中的外屏会各显示一块相同的灰阶色块。
3. 把内屏调到常用亮度。在应用里调整外屏滑块，点击「应用亮度」。
4. 两块屏幕看起来接近时，点击「保存当前校准点」。建议在偏暗、中等、偏亮时各保存一个点。
5. 点击「完成校准」。应用会在已保存的点之间插值，并在校准结束后应用该屏的微调与上下限。

## 常见问题

- **外屏显示 DDC/CI 无响应**。检查显示器实体菜单中的 DDC/CI 设置，尝试减少转接环节后重新检测。若系统亮度被多个工具同时控制，可先暂停其他工具再试。
- **合盖时亮度不跟随**。内屏不可用时，自动同步暂停，外屏保持当时的亮度。
- **两个屏幕的百分比不一样**。百分比是各自设备的亮度档位。以灰阶色块和实际观感校准，外屏可以用不同的百分比获得接近的观感。

## 从源码构建

在 Apple Silicon Mac 上使用包含 macOS 26 或更新版本 SDK 的 Xcode 工具链。源码内已包含固定版本的 DDC/CI 辅助程序，无需单独安装。

```sh
zsh ScreenSync/build.sh "$PWD/build/屏幕随光.app"
open "$PWD/build/屏幕随光.app"
```

应用使用 SwiftUI 和 AppKit。内屏亮度通过 macOS 的 DisplayServices 读取，登录项由 ServiceManagement 管理。DisplayServices 属于系统私有框架，系统更新后可能需要重新验证兼容性。显示器校准和偏好设置保存在本机。

DDC/CI 由 [m1ddc](https://github.com/waydabber/m1ddc) 提供。仓库包含上游提交 [9d75fb6](https://github.com/waydabber/m1ddc/commit/9d75fb6c407ac60dc77a9e32c43d60fd0e6d1612) 的源码和 [MIT 许可](m1ddc/LICENSE)。
